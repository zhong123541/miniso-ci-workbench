# 竞品情报工作台

一个**单文件、零依赖、双击即用**的竞品情报与周报生成工具，面向兴趣消费（潮玩 / 生活杂货）赛道，覆盖名创优品、泡泡玛特、TOP TOY、大创 DAISO、Five Below、Flying Tiger。

> 打开方式：双击 `index.html`，用 Chrome / Edge 打开即可。不需要装任何东西，不需要联网。

---

## 它解决什么问题

竞品跟踪岗位的日常，本质是「把散落在官网、财报、社媒、新闻里的碎片，在固定时间变成一份能被人读的结论」。

这件事人工做一次约 **3 小时**，其中约 **80% 是搬运和归类，20% 才是判断**。这个工具把搬运和归类自动化，把 20% 的判断留给人。

| | 人工基线 | 本工具 |
|---|---|---|
| 收集整理 | 8 个品牌 × 官网/财报/社媒/新闻 ≈ 3 小时 | 更新数据 15 分钟 |
| 归类与成稿 | 手动拼周报，格式每次重来 | 一键生成初稿 |
| 判断与改写 | — | 20 分钟 |
| **合计** | **≈ 3 小时** | **≈ 35 分钟** |

## 六个模块

**1. 概览 Dashboard**
四张 KPI 卡（两家公司的最新营收、门店、毛利率），门店区域结构的归一化对比图，以及「战略分岔：两种增长模型」——名创的「规模 × 渠道 × IP 授权」对泡泡玛特的「自有 IP × 高毛利」。这是整个工具最想让人带走的一页。

**2. 事件流 Signals**
27 条结构化事件，可按品牌、类型、时间窗、关键词四维筛选。每条带日期、地区、影响力权重、原文链接：已核实的事件直连原始报道，仅有媒体转述的标「公开报道」。

**3. 海外声量 Global**
7 条海外社媒与市场信号，按地区筛选，每条都给出「对我们意味着什么」。右侧洞察按信号强度与结构自动生成。这块专门对应 JD 里「能访问外网、熟悉海外常用社交媒体」那一条。

**4. 周报生成 Report**
选统计窗口和品牌范围 → 生成一份结构化周报（结论 / 关键事件 / IP 与品类 / 海外观察 / 海外社媒 / 下周关注）。左侧是 Markdown 源文，可直接改；右侧实时预览；支持复制、下载 `.md`、打印成 PDF。

结论不是套话堆的，是**规则引擎**按数据算出来的：比如同时抓到两家财报就会自动对比增速与毛利结构，抓到「净亏 / 高基数 / 闭店」就会生出风险提示，某个品牌窗口内零事件就会提示「监测缺口」。

**5. IP 图谱 IP Map**
泡泡玛特 7 个 IP 的半年营收结构（含增速）、三种 IP 供给模式的对比、名创的授权 IP 覆盖矩阵，以及按「空白度 × 品类契合 × 增长势能」打分的三条签约建议。

**6. 数据与说明 Method**
数据来源表（14 条，标注「已核实 / 公开报道」）、可信度边界、CSV 导入格式，以及「AI 做了什么 / 我做了什么」的说明。

## AI 做了什么 / 我做了什么

这一页是特意放的，因为 JD 要的是「会用 AI 的人」，不是「会按生成键的人」。

- **AI（辅助）**：检索公开信息、抽取事件要素（品牌 / 类型 / 地区 / 影响力）、把原始链接与数字结构化、生成报告初稿骨架、按规则给出 IP 签约建议。
- **我（判断）**：定义「什么算一条值得进周报的事件」、设定影响力权重、剔除营销软文、识别两家公司财报期不同不可直接比较、把「规模 vs 毛利」提炼成可对话的战略分岔。

一句话：**机器负责不遗漏，人负责不失焦。**

## 怎么扩展

三种方式，都不需要改代码：

1. **加一条今天的新闻** —— 点右上角「+ 添加事件」，填日期、品牌、类型、标题，周报会自动带上。
2. **换一批数据** —— 「导入数据」支持 CSV / JSON。可直接用附带的 `sample-events.csv` 试。表头按名字匹配，列顺序不敏感：

   ```
   日期,品牌,类型,标题,地区,影响力,来源,链接
   2026-10-15,名创优品,开店,新加坡乌节路旗舰店开业,东南亚,4,公司公告,
   ```

3. **导出** —— 事件流页可导出当前筛选结果为 CSV；周报页可导出 Markdown 或直接打印成 PDF。

想改内置数据，打开 `index.html` 搜 `SEED_EVENTS`（事件）、`IP_REVENUE`（IP 营收）、`IP_MATRIX`（覆盖矩阵）、`SOURCES`（来源表），都是普通对象数组。

## 每日自动更新

事件流每天**北京时间 00:00** 由 GitHub Actions 自动更新，无需人工操作：

1. `daily-data-update` 流水线抓取 6 个品牌（中英文关键词）近 48 小时 Google News RSS；
2. DeepSeek API 做结构化提取：去重、剔除软文、按战略重要性打 1–5 分影响力；
3. 合并进网页内置数据（保留最新 50 条），更新快照日期；
4. 自动提交推送，Pages 自动重建——访客看到的始终是当天快照。

- 无新事件时自动跳过提交，不会产生空提交；
- 海外声量 7 条信号保持人工更新（社媒抓取受限，见下）；
- 自动提取的质量略低于人工精选，每条仍附来源链接可回查；
- 想手动触发：仓库 Actions 页 → `daily-data-update` → Run workflow。

## 数据与边界

- **事件流每日自动更新（北京时间 00:00）；海外声量 7 条信号为人工快照（2026-11-02）。**
- 核心财务与门店数据来自公司披露（新华财经、东方财富/广州日报、DAISO 官网等），可追溯、已核实。
- 部分联名与战略事件仅有媒体转述，已在来源表中标注「公开报道」，事件流里也用 `≈` 标出日期为推断值的条目。
- 海外信号的「热度」是本工具自设的观察强度，**不是平台播放量**，报告里不要写成具体数字。
- **不做实时爬虫**：TikTok / Instagram 等平台的抓取受条款与反爬限制，写成爬虫在演示时容易翻车。所以采用「公开数据快照 + 手动更新」的混合方式——真数据、能跑、不会因为平台改版就崩，也符合合规要求。
- 这不是投资建议。

## 三分钟演示脚本

如果要在面试里讲，建议按这个顺序，别一上来讲技术：

1. **先说痛点**（20 秒）：竞品周报人工做一次 3 小时，80% 是搬运。
2. **打开概览页**（40 秒）：指「战略分岔」那张卡——名创用利润换渠道，泡泡玛特用自有 IP 吃毛利，两者 H1 增速已收敛到 5 个百分点以内。这是你的判断，不是工具的判断。
3. **现场加一条事件**（40 秒）：点「+ 添加事件」，随便填一条今天的新闻，切到周报页点生成——让人看到它是活的，不是截图。
4. **翻到海外声量页**（30 秒）：讲「盲盒机制外溢到美妆与超市」这条——壁垒正从「拿到 IP」转向「IP 运营 + 场景」。这是面试里最容易展开、也最不像实习生能说出来的判断。
5. **展示导出**（30 秒）：打开 `竞品周报_2026-11-02.pdf`，说明这就是能直接发给上级的形态；需要的话现场点「打印 / 存 PDF」再出一份。
6. **收尾讲边界**（30 秒）：为什么不做实时爬虫、数据哪些已核实哪些是转述——**主动说局限，比被问出来强**。

不方便现场操作时，把 `demo.gif` 发过去即可，它是上面 1–5 步的浓缩版（6 个画面，约 13 秒一轮）。
