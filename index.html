    IP 供给模式对比

    授权广度 vs 自有深度
    名创优品 授权为主

    迪士尼、三丽鸥、吉伊卡哇、哈利波特、芭比、宝可梦等头部 IP 的高频、短周期联名。优势是流量确定性，劣势是同款可被渠道复制、毛利被授权费侵蚀。

    泡泡玛特 自有为主

    LABUBU（THE MONSTERS）、MOLLY、SKULLPANDA、CRYBABY、星星人、Hirono 等自有 IP 矩阵。优势是毛利与定价权，劣势是单一 IP 生命周期风险。

    TOP TOY 混合

    小玉、堆堆、孢绒绒等自有 IP 起步，同时承接授权。定位是名创体系内的「潮玩专业店」，2026 Q1 收入同比 +51.4%，海外仅 39 家门店，处在早期。

    这个工具解决什么问题

    竞品跟踪岗位的日常，本质是「把散落在官网、财报、社媒、新闻里的碎片，在固定时间变成一份能被人读的结论」。这件事人工做一次约 3 小时，其中 80% 是搬运和归类，20% 才是判断。

    本工具把搬运和归类自动化，把 20% 的判断留给人——这也是我在简历里想说明的：AI 不是替我写报告，是替我腾出做判断的时间。

    AI 做了什么 / 我做了什么

    • AI（辅助）：检索公开信息、抽取事件要素（品牌 / 类型 / 地区 / 影响力）、把原始链接与数字结构化、生成报告初稿骨架、按规则给出 IP 签约建议。
    • 我（判断）：定义「什么算一条值得进周报的事件」、设定影响力权重、剔除营销软文、识别两家公司财报期不可直接比较、把「规模 vs 毛利」提炼成可对话的战略分岔。

    换句话说：机器负责不遗漏，人负责不失焦。

    时间账

    人工基线：8 个品牌 × 官网 / 财报 / 社媒 / 新闻 ≈ 3 小时，产出零散的笔记。
    本工具：更新数据 15 分钟 + 判断与改写 20 分钟 ≈ 35 分钟，产出可直接发送的周报 + 可追溯的数据表。

    怎么用

    • 加一条今天的新闻：点右上角「+ 添加事件」，填日期、品牌、类型、标题即可，周报会自动带上。
    • 换一批数据：「导入数据」支持 CSV / JSON，格式见下方示例。
    • 出周报：周报生成页选窗口 → 生成 → 左侧改措辞 → 导出 .md 或直接打印成 PDF。
